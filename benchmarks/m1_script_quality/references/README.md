# Reference Script Contract

The project collects reference scripts representing desirable storytelling outputs, separated into two categories. 

Do NOT download or reproduce copyrighted transcripts unless appropriately permitted. Store metadata instead.

## Category A — Creator References

Approximately 5–10 scripts/videos from the project owner's own channel or creator workflow that represent desirable output.

## Category B — External References

Approximately 5–10 examples whose storytelling characteristics are worth studying.

## Reference Format

Store reference records with the following fields:
- reference ID
- URL
- creator/channel
- video type
- why selected
- creator notes
- observed storytelling characteristics

## Reference Analysis Dimensions

Candidate observation dimensions (NOT yet frozen Script Quality metrics):
- Hook construction
- Setup speed
- Narrative density
- Chronology handling
- Scene compression
- Dialogue usage
- Commentary
- Humor
- Emotional emphasis
- Suspense
- Open loops
- Callbacks
- Reveal timing
- Transition quality
- Ending hook
- Narrator personality
- Factual precision
